# Morse Code Translator

A simple command-line Morse Code Translator written in C.

This project can convert normal text into Morse code and Morse code back into readable text. It supports English letters (A-Z), numbers (0-9), and spaces between words.

## Features

- Convert Text to Morse Code
- Convert Morse Code to Text
- Supports English letters (A-Z)
- Supports numbers (0-9)
- Supports word separation using `/`
- Menu-driven command-line interface
- Handles invalid menu input

## Example

### Text to Morse

Input:

HELLO WORLD

Output:

.... . .-.. .-.. --- / .-- --- .-. .-.. -..

### Morse to Text

Input:

.... . .-.. .-.. --- / .-- --- .-. .-.. -..

Output:

HELLO WORLD
